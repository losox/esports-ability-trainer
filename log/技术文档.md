# 技术文档 — 电竞能力训练平台

> 最后更新：2026-08-27

## 一、系统架构

```
浏览器
  ├── Astro SSG 静态页面（首页/关于/SEO页 — 零客户端JS）
  └── React 岛屿（交互页面 — client:load / client:only="react"）
        ├── 认证组件（LoginForm / RegisterForm）
        ├── 仪表盘（Dashboard）
        └── 训练组件（D1-D8，每个内含 Three.js 3D 场景）

Supabase (BaaS)
  ├── PostgreSQL 数据库
  │     ├── profiles / sessions / scores / achievements / follows / training_plans / plan_items
  │     └── RLS 行级安全策略
  ├── Auth（邮箱密码 + OAuth GitHub/Google）
  └── Edge Functions（未来扩展）

Vercel
  ├── 静态托管 + 全球 CDN
  └── 自动部署（GitHub main 分支 push 触发）
```

## 四、数据模型

### profiles（用户资料）

| 字段             | 类型        | 说明             |
| ---------------- | ----------- | ---------------- |
| id               | uuid PK     | = auth.users.id  |
| username         | text unique | 用户名           |
| preference       | text        | fps / moba / all |
| sensitivity      | real        | 鼠标灵敏度       |
| allow_comparison | boolean     | 是否允许被比较   |
| avatar_url       | text        | 头像URL          |

### sessions（训练会话）

| 字段         | 类型     | 说明                   |
| ------------ | -------- | ---------------------- |
| id           | uuid PK  |                        |
| user_id      | uuid FK  | → profiles.id          |
| dimension_id | smallint | 1-8                    |
| version      | text     | fps / moba / universal |
| total_score  | integer  | 会话总分               |
| group_count  | integer  | 组数                   |
| duration_ms  | integer  | 时长                   |

### scores（单组成绩）

| 字段             | 类型     | 说明          |
| ---------------- | -------- | ------------- |
| id               | uuid PK  |               |
| session_id       | uuid FK  | → sessions.id |
| user_id          | uuid FK  | → profiles.id |
| dimension_id     | smallint | 1-8           |
| group_index      | integer  | 组序号        |
| score            | integer  | 分数          |
| sub_metrics      | jsonb    | 子指标        |
| is_personal_best | boolean  | 是否个人最佳  |

### 其他表

- **achievements**：用户成就/徽章
- **follows**：单向关注关系
- **training_plans**：训练计划
- **plan_items**：训练计划项

### 模块文件结构（每个维度）

```
src/modules/dX-name/
  ├── logic.ts              # 纯函数：计分、难度计算、等级评定
  ├── scene.ts              # Three.js 场景：继承 SceneBase
  └── __tests__/logic.test.ts  # 单元测试

src/components/training/ComponentName.tsx  # React 组件：HUD + 场景容器
src/pages/train/dX.astro                   # 英文页面
src/pages/zh/train/dX.astro                # 中文页面
```

### SceneBase 共享基类

- 提供：WebGLRenderer、Scene、PerspectiveCamera、灯光、雾、ResizeObserver、Pointer Lock
- 摄像机模式：first-person (0,1.6,0) / isometric (8,12,8) / fixed-front (0,2,8)
- 灯光：AmbientLight(0x404050,0.6) + DirectionalLight(0xff8844,0.8) + DirectionalLight(0x4488ff,0.3)
- 雾：Fog(0x161618, 10, 50)
- 子类实现：onInit() 场景初始化 / onUpdate(delta) 每帧更新
- dispose()：遍历所有 Mesh dispose geometry + material，释放 pointer lock

## 六、多语言策略

- URL 路由：`/` = 英语（默认），`/zh/` = 中文
- 不做浏览器语言自动检测
- 翻译文件：`src/i18n/en.json` + `src/i18n/zh.json`
- 翻译工具：`src/i18n/ui.ts` — getTranslations(locale), getLocalePath(locale)
- 规则：任一语言修改，另一语种必须同步
